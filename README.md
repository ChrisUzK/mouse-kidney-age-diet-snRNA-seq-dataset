# Co-expression analysis of age and diet effects on the mouse kidney

Analysis code and figures for the master's thesis

**"Co-expression Analysis of Age and Diet Effects on the Mouse Kidney"**
Christian Mierau, M.Sc. Computational Biology, University of Cologne, 2026
AG Beyer, CECAD (Cologne Excellence Cluster on Aging and Aging-Associated Diseases)

The repository state that belongs to the submitted thesis is tagged `thesis-submission`.

## Summary

The thesis analyzes gene co-expression in single-nucleus RNA-seq data of the mouse kidney
proximal tubule (segments PT-S1, PT-S2, PT-S3). Eight male C57BL/6N mice were studied in a
2×2 design of age (4 and 24 months) and diet (ad libitum feeding or caloric restriction),
with two animals per condition.

The pipeline covers gene selection, metacell construction and pooling strategies,
functional coherence and reproducibility of co-expression, a linear model of gene
connectivity, term-level block connectivity of GO:BP terms, and the analysis of the
segmental axis of the proximal tubule.

## Data

The snRNA-seq data were generated by the Nephrolab of Prof. Roman-Ulrich Müller (Center for
Molecular Medicine Cologne) and preprocessed by Francisco Lopes (AG Beyer). They are not
part of this repository. Requests for access should be directed to the AG Beyer.

The script expects two Seurat objects (after and before depth normalization with
`cellranger aggr`) and the Cell Ranger `molecule_info.h5` files of the eight libraries.
Their locations are set in the `PARAMETERS` section at the top of the script (`data_path`,
`data_path_prenorm`, `mol_root`) and have to be adapted to the local environment.

## Running the analysis

```r
source("00_pipeline.R")
```

The script runs from top to bottom without further input. Diagnostic plots are written to
`out_dir`, the thesis figures to `out_dir/thesis_figures/`, and a summary of the run
(parameters, sample assignment, package versions) to `00_run_summary.pdf`. All random
steps use a fixed seed (12345).
